👤

Profile Mode

Persistent Identity

Maintain consistent fingerprint across all sessions. Perfect for long-term accounts and normal browsing.

  • Same fingerprint every session
  • Cookies and history saved
  • Believable long-term identity
  • Natural profile evolution
  • Low detection risk
🎭

Stealth Mode

Dynamic Randomization

New random fingerprint each session. Ideal for one-time tasks and maximum anonymity.

  • Random fingerprint each time
  • No data persistence
  • Maximum anonymity
  • Perfect for automation
  • Impossible to track
🤖

Headless Mode

Automated Operations

Optimized for scripts and automation. Runs without visible browser window.

  • No visible window
  • Faster performance
  • Perfect for scripts
  • Batch operations
  • Detailed logging

💡 Real-World Use Cases

📱 Social Media Management

Mode: 👤 PROFILE MODE

Create a persistent profile for managing social media accounts. Your consistent fingerprint builds trust with platforms, cookies persist across sessions, and you appear as a legitimate long-term user.

🔍 Web Scraping

Mode: 🎭 STEALTH MODE

Scrape thousands of pages with different fingerprints for each request. Websites cannot track or block you, and you maintain maximum anonymity throughout the operation.

🛒 Online Shopping

Mode: 👤 PROFILE MODE

Maintain shopping cart, saved addresses, and preferences across sessions. Build purchase history and receive personalized recommendations while staying anonymous.

🧪 Security Testing

Mode: 🤖 HEADLESS MODE

Run automated security tests and penetration testing with headless browsers. Fast, efficient, and perfect for batch operations.

✅ Best Practices

  • Create 3-5 profiles for different purposes (work, personal, shopping)
  • Use Profile Mode for 90% of your browsing
  • Switch to Stealth Mode only for sensitive one-time tasks
  • Let auto-detection handle emergency situations
  • Review and evolve profiles monthly
  • Backup your profiles regularly

⚠️ Important Warnings

  • Do NOT use Profile Mode for illegal activities
  • Do NOT share profiles between multiple people
  • Do NOT ignore detection warnings
  • Do NOT create unrealistic profiles
  • Always match proxy location with profile location
