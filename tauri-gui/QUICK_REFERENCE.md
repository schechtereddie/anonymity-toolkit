# 🎭 Dual-Mode Operation - Quick Reference Card

## 🚀 Quick Start (30 seconds)

```
1. Launch app → python launch_enhanced_browser.py
2. Click "👤 Profile Mode" button
3. Click "Create New" → Enter name → Create
4. Start browsing with persistent identity!
```

## 🎯 When to Use Each Mode

| Situation | Use This Mode | Why |
|-----------|--------------|-----|
| Daily browsing | 👤 Profile | Consistent identity, less CAPTCHAs |
| Social media | 👤 Profile | Build trust, maintain accounts |
| Online shopping | 👤 Profile | Save cart, preferences, history |
| Web scraping | 🎭 Stealth | Different fingerprint each request |
| One-time task | 🎭 Stealth | Maximum anonymity, no tracking |
| Automation | 🤖 Headless | Fast, efficient, scriptable |
| Testing | 🧪 Testing | Try different configurations |

## 🔄 Common Workflows

### Create & Use Profile
```
1. Click "👤 Profile Mode"
2. Click "Create New"
3. Enter name (e.g., "Work_Browsing")
4. Select location (optional)
5. Click "Create Profile"
6. Browse normally - fingerprint stays same!
```

### Switch to Stealth
```
1. Click "🎭 Stealth Mode"
2. Confirm warning dialog
3. Browse anonymously - new fingerprint each time!
```

### View Help
```
1. Click ❓ button on mode indicator
   OR
2. Click mode indicator itself for details
   OR
3. Hover over any button for tooltip
```

## 🎓 Key Concepts (Remember These!)

### Profile Mode
```
✅ SAME fingerprint every session
✅ Cookies SAVED
✅ History ACCUMULATED
✅ Use for LONG-TERM accounts
```

### Stealth Mode
```
✅ NEW fingerprint every session
✅ Cookies CLEARED
✅ History NONE
✅ Use for ONE-TIME tasks
```

### Auto-Detection
```
System automatically switches to Stealth when:
❌ CAPTCHA detected
❌ "Bot detected" message
❌ "Suspicious activity" warning
❌ Access denied error
```

## 📊 Profile Data Stored

Each profile contains:
- ✅ Demographics (age, gender, occupation)
- ✅ Location (city, country, timezone)
- ✅ Hardware (CPU, GPU, screen)
- ✅ Browser (user agent, fingerprints)
- ✅ Behavior (browsing patterns)
- ✅ Interests (websites, searches)
- ✅ Cookies and history
- ✅ Evolution log
