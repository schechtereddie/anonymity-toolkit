## 🔧 Troubleshooting

### **Common Issues**

#### **Browser Won't Launch**
```
Error: Browser not found
Solution: Install the browser or check the path in browser settings
Command: python launch_enhanced_browser.py --install-browser
```

#### **Proxy Connection Failed**
```
Error: No working proxies
Solution: Run enhanced proxy scraping with more sources
Command: Click "Smart Scrape (50+ Sources)" in Proxy Manager tab
```

#### **Profile Loading Error**
```
Error: Profile not found
Solution: Create a new profile or check the profiles directory
Command: Use "Create Enhanced Profile" in Profile Manager tab
```

- **Log file**: `enhanced_anonymity_toolkit.log`
- **Status reports**: Export from "Enhanced Status" tab
